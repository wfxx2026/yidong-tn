🚀 GitHub Pages 部署指南

  1. 注册/登录 github.com，点击右上角 ➕ → New repository
  2. 仓库名称填写：yidong-attendance（或任意名称），选择 Public，勾选 Add a README file
  3. 进入仓库 → 点击 Add file → Upload files，上传本 index.html 文件
  4. 进入 Settings → 左侧 Pages → Source 选择 Deploy from a branch → Branch 选 main → 点击 Save
  5. 等待1-2分钟，访问 https://你的用户名.github.io/yidong-attendance 即可在线使用！
  6. 如需自定义域名：在 Pages 设置中填写域名，并在仓库根目录添加 CNAME 文件

提示：GitHub Pages 免费、稳定、全球可访问，数据保存在用户本地浏览器，刷新不丢失！
